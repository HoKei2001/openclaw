## Overview

This video by intellectual property lawyer Rohini explains the unique and nuanced position of software patents in India under the Indian Patents Act 1970. Unlike many other countries where software can be patented outright, India takes a more restrictive approach governed primarily by Section 3K of the Act, which explicitly excludes mathematical methods, computer programs per se, algorithms, and business methods from patent protection. However, this exclusion is not absolute — there is an important exception that creates a pathway for software-related inventions.

The key principle in Indian patent law is that standalone software code cannot be patented (and should instead be protected by copyright), but software that is integrated with hardware and provides a tangible technical effect or solution can be patentable. Examples include software that makes a processor faster or more efficient, software enabling enhanced data compression, or software that improves an electronic device's user interface functionality. The Indian Patent Office uses Computer Related Inventions (CRI) guidelines — particularly the 2017 revision — to evaluate these claims, requiring that the software must solve a technical problem and not merely implement an algorithm in isolation.

The video also references Blacks Law Dictionary's definition of software (a set of commands/instructions to run a computer) and emphasizes that the question of patentability is determined case by case. Inventors with exclusive software that cannot be patented but who still want some form of protection are advised to consult a professional IP attorney, as there may be alternative strategies available.

## Key Takeaways

- India's Section 3K bars patents for standalone software, mathematical methods, algorithms, and business methods
- Exception: software integrated with hardware that provides a technical effect or solves a technical problem can be patented
- The 2017 CRI (Computer Related Inventions) guidelines require that patentable software must solve a technical problem, not just implement algorithms
- Standalone software code is best protected by copyright, not patents, in India
- Examples of potentially patentable software in India: OS components improving processor speed, medical imaging software integrated with sensors, novel compression algorithms tied to specific hardware
- India's approach is "more nuanced" than the U.S. — all cases are evaluated individually under Section 3K
- A patent attorney or agent should be consulted for a case-by-case patentability analysis
