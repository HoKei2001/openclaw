## Overview

This USPTO Open Data Portal (ODP) tutorial video explains how to use the PTAB (Patent Trial and Appeal Board) data module within the USPTO's Open Data Portal. The video is a practical walkthrough for researchers, patent attorneys, and data analysts who need to search, view, filter, and download PTAB proceeding data, including trial proceedings, appeal decisions, and interference data.

The PTAB module on the ODP is organized into three main categories: Trials (with subtabs for Trial Proceedings, Trial Decisions, and Trial Documents), Appeals, and Interferences. A global search tool allows users to search across all tabs simultaneously using a single query. Table-level search bars, filter panels on the left side, and customizable column displays allow users to refine and focus their results. Individual records can be clicked to open a detailed slide-out panel showing trial status, decision dates, associated applications, documents, and transactions. Data can be downloaded in CSV or JSON format, with a maximum of 3,000 records per download.

For users who need to integrate PTAB data into their own applications, the video introduces the API query feature, which generates the code needed to pull PTAB data from the USPTO's servers via the Open Data Portal API. Using the API requires an approved ODP API key, obtained through a verified MyODP account using ID.me verification.

## Key Takeaways

- The USPTO Open Data Portal PTAB module contains three data categories: Trials, Appeals, and Interferences.
- A global search tool searches across all tabs and subtabs simultaneously.
- Left-panel filters and customizable column displays allow precise data refinement.
- Individual trial, appeal, or interference records can be expanded to show detailed information including status, decision dates, and associated documents.
- Data can be downloaded as CSV or JSON, up to 3,000 records per download.
- The API query feature provides code for integrating PTAB data into external applications.
- API access requires an approved ODP API key obtained via an ID.me-verified MyODP account.
- Questions can be directed to data@uspto.gov or the PTAB FAQ page on the ODP.
