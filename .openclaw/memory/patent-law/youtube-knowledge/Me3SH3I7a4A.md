## Overview

This IPO Trinbago tutorial provides a step-by-step walkthrough of filing a patent application through WIPO's Yfile (eFile) online platform. The video is structured as a practical screen-sharing demonstration, walking through each required field and action in the platform's interface — from login through final submission. It covers the full submission workflow for a PCT Chapter 2 application, which is the most complex application type available on the platform, making it a useful reference for other application types as well.

The tutorial demonstrates the five application type options available in the platform (four patent types plus a utility certificate), the required fields for the application record (title, abstract, claims count, page count, main drawing image in JPEG or BMP format), and the applicant/inventor detail entry process including the option to copy an applicant's details directly to an inventor record. Priority details, the mandatory PCT publication page upload for PCT applications, and optional document attachment are all covered. The video walks through the validate function (which checks for missing required fields and returns specific error messages) and shows the difference between saving a draft for later editing and final submission, demonstrating that submitted applications are tracked in the workbench with a "submitted" status.

## Key Takeaways

- WIPO's Yfile platform requires account registration before filing; accounts can be requested via the relevant IP office
- The platform supports five application types including PCT Chapter 1, PCT Chapter 2, and a utility certificate
- Required application fields include title, abstract, claim count, page count, and a main drawing image (JPEG or BMP format)
- Applicant and inventor details can be entered separately; an applicant can be copied as an inventor with a checkbox
- PCT Chapter 2 applications require mandatory upload of the PCT publication page
- The validate function checks all required fields before submission and returns specific error messages for missing data
- Applications can be saved as drafts for later editing before submission; submitted applications appear in the workbench with a "submitted" status

## Best For

Patent applicants and IP professionals who need a hands-on tutorial for using WIPO's Yfile online filing platform to submit a patent application, particularly in PCT Chapter 2 format.
