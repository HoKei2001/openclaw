# Novelty Requirement for Patentability

## Overview

Patent attorney Josh Goldberg of Nath, Goldberg & Meyer explains the novelty requirement for U.S. patents in this informative video. He begins with the three basic requirements for patentability — the invention must be new (novel), useful, and non-obvious — then focuses specifically on what "new" means under current U.S. patent law. The novelty standard is rooted in the America Invents Act: a claimed invention lacks novelty if it was patented, described in a printed publication, in public use, on sale, or otherwise available to the public before its effective filing date.

The critical rule for novelty is that no single prior art disclosure can teach every element of the claim. For a claim to be rejected as lacking novelty, the examiner must identify one single reference — a patent, publication, public use, or product — that clearly describes every feature being claimed. If any single element is missing from that reference, the novelty requirement is satisfied for that reference (though obviousness may still be an issue if elements from multiple references can be combined). Goldberg illustrates this with a memorable example: a one-legged chair would be novel not because chairs are unknown or legs are unknown, but because no single prior disclosure taught a chair with exactly one leg for balance.

Goldberg also addresses the practical limits of patent searches, noting that no search can cover every publication or use on earth — so a prior art search cannot definitively prove an invention is novel, only that no conflicting prior art has been found so far. Even after a patent is granted, obscure prior art could still surface. He encourages inventors to contact him for a consultation to explore whether their inventions are novel and worth protecting.

## Key Takeaways

- The novelty standard: an invention is not novel if it was publicly known, used, or patented before the effective filing date
- A single prior art reference must teach every claimed element to defeat novelty — if even one element is missing, novelty survives that reference
- The America Invents Act (current U.S. law) uses a broad "otherwise available to the public" standard for prior art
- No prior art search can guarantee novelty — only that no conflicting reference has been found yet
- Even after a patent is granted, previously undiscovered prior art can be cited to invalidate it
- Useful analogy: a one-legged chair is novel because no prior disclosure taught exactly this configuration, even though chairs and legs are both known
- Novelty and obviousness are separate tests; an invention can be novel but still fail the obviousness requirement
