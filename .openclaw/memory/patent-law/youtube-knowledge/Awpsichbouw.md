## Overview

This tutorial by Erinnae Baker provides a step-by-step walkthrough of the USPTO's patent search database, covering both the Patent Full Text Database (for granted patents) and the Patent Application Full Text Database (for pending applications). The video is aimed at beginners who need to search for prior art, check whether a similar invention already exists, or find technical specifications for a past patent.

The tutorial begins by navigating to the search patents section of the USPTO website, where Baker notes several useful resources: a guide to what is and is not patentable, patent forms, and a fee schedule. The main focus is the Patent Full Text Database, which offers full-text search from 1976 onward (with limited information available back to 1790). Three search options are covered: quick search (two keyword fields with a Boolean operator), patent number search (for when the exact patent number is known), and advanced search (for multi-field queries using field codes).

The quick search demonstration uses the example of searching for "bicycle AND speedometer" and shows how restricting the search to a specific field (title, inventor name, description) can narrow results significantly. The advanced search is briefly introduced as more complex but useful for building queries involving multiple keywords across multiple fields simultaneously — for example, finding patents where the title contains both "bicycle" and either "odometer" or "speedometer." Individual patent records are shown to include patent number, issue date, inventor information, related patents, and description. Images must be accessed through a separate link. The tutorial closes by noting that the application database works identically to the patent database.

## Key Takeaways

- The USPTO patent database has two main sections: Patent Full Text Database (granted patents, full text from 1976) and Patent Application Full Text Database (pending applications)
- Quick search supports two keyword fields with Boolean operators (AND, OR, NOT); field restrictions (title, inventor, description, etc.) significantly narrow results
- Patent number search is available when the exact patent number is known
- Advanced search uses field codes (e.g., TTL for title, IN for inventor) and supports complex Boolean queries with parentheses across multiple fields
- Individual patent records include patent number, issue date, inventor information, related patents, and description; images require clicking a separate link
- The quick search tool is sufficient for most focused searches; the advanced search is useful when searching multiple fields or building complex multi-concept queries
- Patents can be purchased directly through the website by adding them to a cart

## Best For

Beginners using the USPTO patent database for the first time who need a hands-on tutorial covering the quick search, patent number search, and advanced search interfaces across both granted and pending patent databases.
