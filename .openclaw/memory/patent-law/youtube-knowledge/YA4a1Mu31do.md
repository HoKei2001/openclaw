# How to Patent Software

**Channel**: Patent Guru
**URL**: https://www.youtube.com/watch?v=YA4a1Mu31do
**Published**: 2012-03-31

---

## Overview

This video from Patent Guru by registered patent agent Brad Flash provides a practical guide to filing a software patent application. It starts by explaining that software patents fall under utility patents — specifically method patents, which have been used for chemical and biotechnology processes for over a century and now extend to methods performed by computers. Software code itself is protected automatically by copyright (making that easy), but if the software performs a novel and useful method or function beyond basic code, it may also qualify for patent protection.

The video explains the timing challenge unique to software patents: because the U.S. follows a first-to-file system, publishing or making software available for sale can block patent rights if no application has been filed first. In the U.S., there is a 12-month grace period after first public disclosure, but the recommended practice is to file a provisional patent application first, then do a soft launch to test the market and attract investors, then file the full non-provisional application within one year. The patent expires 20 years from the filing date. Cost ranges are discussed: a patent attorney or agent can charge $1,000 to $40,000 depending on complexity; doing it yourself saves attorney fees but requires significant effort.

The video also notes that it has become progressively harder to get broad software patents in recent years (compared to a decade earlier), which the presenter views as appropriate given the history of abuse. Free templates and software patent examples are available at patentfile.org/software.

## Key Takeaways

- Software patents are utility (method) patents protecting novel functions or processes performed by software
- Software code itself is automatically protected by copyright; a patent is needed to protect the underlying method or function
- File before publishing or launching your software — the U.S. has a 12-month grace period but earlier is always better
- Recommended timeline: file provisional patent → soft launch → file non-provisional within one year
- Costs range from about $1,000 (simple, with patent agent) to $40,000 (complex, with law firm)
- Inventors can file their own patent application without an attorney (as the inventor filing pro se)
- It is increasingly difficult to obtain broad software patents; applications must describe specific technical innovations

## Best For

Software developers and inventors who want a practical, step-by-step introduction to the software patent filing process and timeline, including cost ranges and the provisional-to-non-provisional pathway.
