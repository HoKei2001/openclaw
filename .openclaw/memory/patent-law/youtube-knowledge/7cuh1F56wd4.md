## Overview

Brad Foss from File a Patent Online (patentfile.org) introduces a free provisional patent application template available in both Google Docs and Microsoft Word formats. The video briefly walks through the structure and features of the template, explains how to use it, and provides background on the firm offering the resource.

## Key Takeaways

- The free template is available in both Google Docs and Microsoft Word (.docx) versions and both work identically; users can request either format
- All placeholder text in the template is displayed in red, making it easy to identify exactly what needs to be replaced with the inventor's own content
- All required sections of a provisional patent application are pre-structured in the template, allowing the applicant to simply work through the document sequentially
- Paragraph numbering is automatic — each new paragraph is numbered in the format required by the USPTO, so applicants do not need to manage numbering manually
- A claims section is included in the template; claims are not required for a provisional patent application, but inventors who are comfortable writing claims can include them
- The final page of the template includes an abstract section, which should be 150 words or fewer summarizing the invention
- The template is offered by Brad Foss and his partner Stephen, experienced patent professionals based in Charlotte, NC, who work directly with clients without using junior associates or interns
