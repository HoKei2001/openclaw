## Overview

This Hindi-language video by Dr. Prachi Chopra from Intellect Bastion addresses one of the most frequently asked questions by inventors from the computer science and software development community: can a software program be patented in India? The video targets inventors who are confused by the ongoing online debate about Section 3K of the Indian Patent Act, which excludes computer programs, algorithms, mathematical methods, and business methods from patentability.

The key clarification: a standalone computer program or line-by-line coding in any programming language (R, C, C++, Java, etc.) is not patentable on its own — it is protectable by copyright. However, when a software invention involves a combination of hardware and software that produces a tangible technical improvement, that system-level invention can be patented. The Indian Patent Office looks for a demonstrable technical effect or technical contribution — such as improved computer resource management, faster processing speed, enhanced user interface functionality, or better data compression — rather than the code itself.

Four illustrative examples of patentable software inventions are given: a novel operating system component that manages memory allocation in a multicore processor and significantly improves speed and efficiency; embedded software in a new medical imaging device that is deeply integrated with sensors and processing units to produce superior image clarity; industrial software tightly integrated with specialized manufacturing or healthcare machinery that provides a novel control function unique to that hardware; and a software-based video compression method using a novel algorithm tightly integrated with a video processing chip's architecture, achieving a significantly higher compression ratio. The key phrase to remember: "any software program that provides a tangible technical improvement is always patentable."

## Key Takeaways

- Standalone software code (line-by-line programming) is NOT patentable in India — it is protected by copyright instead
- Software that provides a tangible technical improvement through hardware-software interaction IS patentable
- The Indian Patent Office evaluates the technical effect and contribution, not the coding itself
- Section 3K excludes computer programs "per se" — meaning pure code without hardware interaction
- Four categories of patentable software: OS components improving hardware performance, embedded software in devices, industrial control software, and novel algorithmic methods integrated with specific hardware
- Three standard patentability criteria still apply: novelty, inventive step, and industrial applicability
- Patent claim drafting must emphasize the hardware interaction and technical advancement, not the algorithm itself
