# USPTO Provisional Patent Application Requirements

## What a PPA Provides

- 12-month priority date (not extendable)
- "Patent Pending" status
- Does NOT get examined by USPTO
- Must file Non-Provisional within 12 months to preserve priority

## Minimum Requirements (35 U.S.C. 111(b))

1. Written description of the invention
2. Any drawings necessary to understand the invention
3. Cover sheet (or ADS) with:
   - Title
   - Inventor name(s)
   - Residence of each inventor
   - Name and address for correspondence
   - Entity status
4. Filing fee

## What Is NOT Required in a PPA

- Formal claims
- Oath or declaration
- Information Disclosure Statement (IDS)
- Abstract (recommended but not required)

## Critical Deadlines

- **12 months** from PPA filing date: must file Non-Provisional
- **11 months**: internal reminder to decide on Non-Provisional
- No extensions available for the 12-month window

## Key Tips

- Disclose as much as possible — PPA scope limits what Non-Provisional can claim
- Include all embodiments/variations even if rough
- Drawings don't need to be formal — sketches are acceptable
- Description should enable a PHOSITA (Person Having Ordinary Skill in the Art) to practice the invention
