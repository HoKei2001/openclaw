# How to create patent drawings

**Channel**: Brian Haney
**URL**: https://www.youtube.com/watch?v=AbjmFwY9amI
**Published**: 2021-03-18

---

## Overview

This short, practical video by Brian Haney demonstrates how to create simple patent drawings using Microsoft Word's text box and flowchart tools — a highly accessible approach for inventors who need basic drawings for a provisional patent application or a simple process-based invention. The video targets beginners who may be intimidated by the drawing requirement and presents a straightforward method that requires no specialized software.

The demonstration walks through creating a three-step flowchart from scratch in Word using text boxes connected by arrows, with a time machine example used as the subject matter. The process shown is: create a text box for each step, duplicate it for the needed number of steps, connect them with arrows, add reference labels using small symbols, and number each labeled element using a consistent numbering scheme. The presenter's preferred convention is to use numbers tied to the figure number (Figure 1 uses 100-series numbers: 100, 101, 102, etc.; Figure 2 uses 200-series numbers), noting this keeps tracking simple when an application has multiple figures.

The video emphasizes that for many process-type or software inventions, a basic flowchart in Word is entirely sufficient as a patent drawing, particularly for provisional applications. The key is that the drawing illustrates the invention clearly enough to identify its components.

## Key Takeaways

- Microsoft Word's text boxes and arrows can create serviceable patent drawings for process and software inventions without specialized drafting software
- The minimal requirement for patent drawings is that they illustrate the invention and allow labeling of key components
- A recommended reference number convention: tie numbers to the figure (Figure 1 → 100, 101, 102; Figure 2 → 200, 201, etc.) for simple, consistent tracking
- Flowcharts are the most accessible drawing format for process-type, software, or multi-step inventions
- Word-based drawings are particularly useful for provisional patent applications where formal drawing standards are not required
- The drawing must include labeled reference numbers tied to the components described in the specification

## Best For

First-time inventors with process-based or software inventions who need a quick, no-cost method for creating basic patent drawings using only Microsoft Word.
