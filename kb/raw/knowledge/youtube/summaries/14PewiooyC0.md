# Is it Too Late to File a Provisional Patent Application? Patents Q&A

**URL**: https://www.youtube.com/watch?v=14PewiooyC0
**Published**: 2025-08-08

## Overview

Silicon Valley patent attorney John Ferrell answers a collection of viewer questions about provisional patent applications in this Q&A video. Topics range from whether a provisional can be filed on a device not yet built (yes, a prototype is not required — only a written description and understanding of how to make and use the invention is needed), to the duration of patent protection when a provisional is converted to a utility application (the 20-year term runs from the non-provisional filing date, giving effectively 21 years of combined patent pending plus patent protection).

A key question addresses what happens when a provisional patent application expires because the inventor lacked funds to file a non-provisional. Ferrell explains that refiling is possible if two conditions are met: no public disclosure has occurred since the original filing, and no intervening inventor has independently filed on the same idea. The new filing gets a fresh priority date — not the original date — and any improvements made in the meantime can be included.

The video also covers administrative details such as whether reference numerals are required on drawings in a provisional (they are not required, since provisionals are informal documents), and strategies for accelerating examination if a competitor begins copying the invention before the patent issues, including the Track One prioritized examination program and accruing damages back to the date of actual notice after publication.

## Key Takeaways

- A working prototype is not required to file a provisional patent application — understanding and description suffice.
- Patent term is 20 years from the non-provisional filing date, so filing a provisional first adds roughly one extra year of protection.
- An expired provisional can be refiled if there has been no public disclosure and no intervening inventor has filed on the same invention.
- A refiled provisional receives a new priority date, not the original one.
- Reference numerals are not required on drawings in a provisional patent application.
- Track One prioritized examination can get a patent granted in approximately one year for an additional fee.
- Actual notice given to an infringer after patent publication can allow damages to be collected back to the date of that notice, even before the patent issues.

## Best For

This video is most useful for independent inventors and early-stage entrepreneurs who have questions about the timing, requirements, and recovery options associated with provisional patent applications.
