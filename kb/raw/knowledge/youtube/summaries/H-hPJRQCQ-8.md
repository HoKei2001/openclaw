## Overview

This official USPTO training video, presented by Rich Fernandez of the E-Mod team, provides a detailed walkthrough of how to file patent application documents in DOCX format through the USPTO's Patent Center system. The video covers the benefits of DOCX over PDF, the non-DOCX surcharge that took effect January 17, 2024, how to use Patent Center's training mode, and a live demonstration of uploading and submitting a DOCX application including the auxiliary PDF option.

## Key Takeaways

- Starting January 17, 2024, a surcharge of up to $400 applies when filing a new non-provisional utility application with specifications, claims, or abstracts in PDF rather than DOCX format
- DOCX filings offer significant advantages over PDF: automatic metadata removal, real-time content-based validation with a downloadable feedback document, automatic section splitting using valid section headers, and no need to manually convert to PDF
- DOCX is not mandatory — all files continue to be accepted in PDF — but the surcharge makes DOCX economically preferable for new utility non-provisional applications
- The auxiliary PDF option allows applicants to submit their own PDF version alongside the DOCX as a backup reference for discrepancy correction; only one auxiliary PDF can be uploaded per submission
- Patent Center offers a Training Mode (simulated environment) where applicants can practice uploading DOCX files and see validation feedback without submitting real data to USPTO systems
- The DOCX surcharge applies to continuations, divisionals, and continuation-in-part applications, but not to provisional, national stage, design, plant, or PCT applications
- Valid section headers (e.g., "Claims," "Abstract," "Background") must be used in a multi-section DOCX for the system to automatically detect and split sections and assign document codes
- DOCX supports embedded images, equations (MathML), and chemical structures (ChemDraw); macros (DOCM files) are rejected for security reasons
