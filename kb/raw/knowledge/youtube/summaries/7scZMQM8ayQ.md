## Overview

This short tutorial demonstrates a specific feature of the ipMAGNET patent search tool: extracting bibliographic terms from a patent or publication for use in further prior art research. The workflow begins by checking a box to enable the "Extract Biblio" function, entering a patent or publication number, and selecting the extraction option. The tool then pulls all searchable bibliographic fields from that patent — such as inventor names, assignees, classification codes, and other metadata.

From the extracted bibliographic data, users can select any specific field (such as an inventor name) and directly run a search for all patents associated with that field. This allows researchers to quickly trace the work of specific inventors or patent families relevant to their prior art investigation. The same extraction functionality is available from any patent appearing in search results, enabling recursive investigation by jumping from one reference to related ones.

## Key Takeaways

- The "Extract Biblio" feature pulls all searchable bibliographic terms from a patent or publication number
- Extracted fields include inventor names, assignees, classification codes, and other searchable metadata
- Any extracted field can be selected from a pull-down menu to run a targeted search on that attribute
- The tool supports recursive prior art investigation: extracting from results leads to further related patents
- This approach complements keyword searching by enabling inventor-based and assignee-based searches
- The feature is available from both the starting patent and from any patent appearing in search results

## Best For

Patent researchers and inventors who want to learn how to use bibliographic term extraction tools to efficiently navigate patent family trees and inventor portfolios during a prior art search.
