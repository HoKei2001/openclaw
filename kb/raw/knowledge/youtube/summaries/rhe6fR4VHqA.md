## Overview

In this screen-recorded tutorial, Silicon Valley patent attorney John Ferrell demonstrates in real time exactly how to file a provisional patent application using the USPTO's Patent Center portal. The video was created in response to a viewer request and runs approximately 20 minutes. Ferrell recommends playing it on a smartphone next to your computer so you can follow along step by step simultaneously.

Before starting, Ferrell explains the filing fee structure: micro entity filers (individuals earning roughly $185,000 or less per year) pay $60; small entities (small businesses or higher-earning individuals) pay $120; and large entities pay $240. He notes that fees change frequently, so amounts may differ at the time of actual filing. The filing path starts at Google, searching for "USPTO," then navigating to the Patents tab, selecting "Filing Online," clicking "Open Patent Center," and finally under New Submissions selecting "Utility Provisional." Filers can proceed as a guest user, though registered accounts provide more functionality.

The application data sheet (ADS) is completed through a web form, requiring the inventor's name and address, a correspondence address including email, the title of the invention, entity status, application type, and number of drawing sheets. Ferrell highlights two elements that are easy to miss and will cause the submission to be rejected or incomplete: the signature field (formatted as backslash-name-backslash) hidden near the end of the ADS form, and the requirement to select a document type description (such as "Specification") from a dropdown menu after uploading PDF files. After submitting, the system generates a filing receipt containing the application number, which must be saved and retained as it is the key to accessing the application later. The video concludes by recommending Ferrell's book "Provisional Patents" available on Amazon as a companion resource.

## Key Takeaways

- Filing fees for a provisional patent application vary by entity type: micro entity $60, small entity $120, large entity $240, and fees change periodically.
- Navigate to the filing portal via USPTO.gov → Patents → Filing Online → Open Patent Center → New Submissions → Utility Provisional.
- Filing as a guest user is possible but a registered account provides full access to manage and track the application.
- The ADS signature field is easy to miss — it requires the format backslash-name-backslash and is located near the end of the form.
- After uploading PDF documents, the document type description must be selected from a dropdown menu (e.g., "Specification") — leaving it blank causes an incomplete submission.
- Pay fees immediately at time of submission to avoid late payment penalties and surcharges.
- The filing receipt containing the application number is a critical document that must be saved for future access to the application.
